## Как работать с материалами

Проще всего открыть нужный ноутбук по ссылке **Colab** в таблице: локальная
установка в этом случае не требуется. Некоторые занятия используют GPU и
загружают наборы данных или веса моделей во время выполнения.

Для локального запуска клонируйте репозиторий и откройте его в JupyterLab:

```bash
git clone https://github.com/SergeyMalashenko/2025_ML3.git
cd 2025_ML3
jupyter lab
```

В репозитории нет единого файла зависимостей: набор библиотек различается от
семинара к семинару и указан непосредственно в соответствующем ноутбуке.
Рекомендуется использовать отдельное виртуальное окружение и устанавливать
пакеты по мере прохождения выбранного материала.

## Структура репозитория

```text
seminars/
├── 01_backprop/       # градиенты и обратное распространение
├── 02_pytorch/        # PyTorch и JAX
├── 03_neuralnetwork/  # полносвязные нейросети
├── 04_convolutions/   # свёртки
├── 05_cnn/            # обучение CNN
├── 06_ssd/            # SSD и YOLO
├── 07_unet/           # сегментация и U-Net
├── 09_crnn/           # CRNN и распознавание текста
├── 10_nlp/            # NLP и attention
├── 11_gpt/            # трансформеры и GPT
├── 12_mamba/          # state-space models и Mamba
├── 13_quant_lora/     # квантизация и LoRA
└── 14_kan_gnn/        # KAN и GNN
```

Ноутбуки с суффиксом `_filled` содержат решения, а варианты `_clear` — задания
для самостоятельной работы. Нумерация каталогов повторяет программу курса;
каталог `08` в текущей версии репозитория отсутствует.
